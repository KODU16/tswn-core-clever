# RC Boss

输入 rc@! 挑战，右侧 Boss 表格保留 rc，图标采用 RbCl@RbCl 的生成图标。

## 本体与技能选择

本体沿用既有 Boss 基础属性：HP 360，内部七围基值 106，内部实战速度 266，初始 MP 53，嘲讽权重 0.000001。正常行动不普攻；可用技能间等概率选择。观察大带来的原生狂暴例外：随后两次自身行动走引擎的强制攻击及倒计时，结束后恢复专属技能选择。冰冻等原生行动限制照常生效。

| 技能 | 使用条件 | 效果与文本 |
| --- | --- | --- |
| 抽卡 | 自己存活的小不足 3 个 | 均匀抽取 1～3 个小，文本“RC发动抽卡，抽到N个小” |
| RC的同学给RC氪了个648 | 自己存活的小不足 3 个 | 均匀抽取 3～5 个小，文本“RC的同学给RC氪了个648，抽到N个小” |
| 观察 | 自己存在存活、HP 大于 0 的召唤物 | 随机观察其中一个，文本“RC观察了目标” |
| 我突然有点担心小 | 自己存在存活的小 | 将当前 HP 最低的小回满，不治疗大或尸体 |

召唤以施法前的数量作为资格检查，不设同时存活硬上限。例如已有 2 个小、648 抽到 5 个时，完整召唤后有 7 个小；达到 3 个后暂停两种召唤，死亡或成长导致小不足 3 个时恢复资格。大不计入小的数量；魅惑换队不改变原召唤者归属。

## 小与受伤反雷

小固定 HP 72、外显七围均为 36。内部六围为 0、实战速度为 160，界面按普通角色的偏移规则显示为 36，不再从旧来源名字构建属性。嘲讽权重保留 1000000000000，不分摊伤害给 RC；自身行动仅尝试原生魅惑，无目标也不普攻。

只有攻击实际扣除 HP，且小在扣血后仍存活时，才向攻击者释放一次完整原生雷击术。未命中、零伤害、护盾完全吸收、致死一击、攻击者是任意 RC 本体时都不触发；反雷链不递归触发反雷。大被攻击不反雷。

## 观察与成长

只从该 RC 自己仍然存活且 HP 大于 0 的召唤物中随机选择，不包括尸体。每次观察使目标的“观察次数”永久增加一层，驱散、净化、普通状态清理不减少层数，界面状态标签会显示层数。效果按观察前的层数及目标身份判定：

- 小、原来 0 层：RC 的外显七围乘 1.2，取整，持续随后两个自身回合；重复获得刷新持续时间，不重复叠乘。台词随机“这确实太小了”或“有点小”。临时属性增益本身可正常驱散，永久观察层数不受影响。
- 小、原来 1 层：原地成长为大，外显七围翻倍，HP 上限与当时剩余 HP 同时翻倍，保留实体、原归属和观察层数。台词随机“还是大了”或“我觉得大了”。
- 大：RC 自己进入原生狂暴两个自身行动，台词“一个两个的怎么都是大雷，我愤怒了”。目标大只增加观察层数，不被施加狂暴。

大自身的行动固定重复“蓄力 → 原生雷击术”，从变身后的第一次行动开始计数。它不再魅惑，也没有受击反雷。

RC 台词共用 Squall 的原生台词段渲染；Squall 原有的临时隐藏开关保持关闭。观察层数、成长身份、属性倍率、行动序列和增益计时全部随战斗快照保存，支持回放与快速续局；新战斗从初始状态开始。

## 验证

rc_tests.rs 覆盖两种抽卡数量与施法前门槛、外显属性、死亡／零血／他人召唤物筛选、观察层数与驱散净化、增益到期、成长 HP 翻倍、大的动作循环与不反雷、最低 HP 治疗、RC 攻击豁免、原生狂暴两次行动，以及真实回放／快速续局／同 seed 重建一致性。
